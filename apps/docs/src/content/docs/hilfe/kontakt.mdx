- **Fragen zu Ihrer Lotta-Seite** (Zugang, Gruppen, Inhalte): Wenden Sie sich an die Admins Ihrer
  Schule, am einfachsten über **Mein Profil** → **Feedback** (siehe [Feedback senden](/nutzen/feedback/)).
- **Fragen zu Lotta selbst**, für Admins und Schulleitungen: Schreiben Sie dem Lotta-Team über
  **Seite verwalten** → **Feedback** → **Feedback an Lotta Entwickler** oder per E-Mail an
  [kontakt@lotta.schule](mailto:kontakt@lotta.schule).
- **Lotta für Ihre Schule:** Alles über Lotta und einen kostenlosen Test finden Sie auf
  [lotta.schule](https://lotta.schule).

Diese Dokumentation ist ein Gemeinschaftswerk. Haben Sie einen Fehler gefunden oder fehlt etwas?
Über **Diese Seite bearbeiten** unten auf jeder Seite können Sie Verbesserungen vorschlagen.

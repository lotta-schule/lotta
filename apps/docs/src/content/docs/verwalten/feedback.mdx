Mitglieder schicken über **Mein Profil** → **Feedback** Fehlermeldungen, Fragen und Ideen an die
Admins (siehe [Feedback senden](/nutzen/feedback/)). Eine Zahl an **Seite verwalten** zeigt neues
Feedback.

Öffnen Sie **Seite verwalten** → **Feedback**. Unter **Feedback von Nutzern** sehen Sie alle
Rückmeldungen mit Name, Thema und Datum; ein Klick zeigt die Nachricht.

<Screenshot
  name="admin-feedback"
  alt="Die Liste der Rückmeldungen mit einer geöffneten Nachricht"
/>

- **beantworten**: Schreiben Sie eine Antwort; das Mitglied erhält sie per E-Mail.
- **weiterleiten**: Betrifft die Rückmeldung Lotta selbst, z.B. einen Fehler, leiten Sie sie mit
  einer eigenen Notiz an das Lotta-Team weiter.
- **Papierkorb**: löscht die Rückmeldung.

## Feedback an das Lotta-Team

Unter **Feedback an Lotta Entwickler** schreiben Sie dem Lotta-Team direkt: Fragen, Wünsche, Lob
oder Kritik. Wir freuen uns über jede Rückmeldung.

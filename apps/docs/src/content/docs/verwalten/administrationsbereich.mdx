Alle Einstellungen Ihrer Lotta-Seite nehmen Sie im Administrationsbereich vor. Sie erreichen ihn
als Admin über **Mein Profil** → **Seite verwalten** (auf dem Smartphone: Menü → **Admin**).
Eine Zahl am Menüpunkt zeigt neues Feedback.

<Screenshot
  name="admin-overview"
  alt="Die Übersicht des Administrationsbereichs mit allen Bereichen"
/>

| Bereich                                         | Was Sie dort tun                                         | Anleitung                                                                                      |
| ----------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Mein Lotta** → **Allgemeines**                | Name, Logo und Domains der Lotta-Seite                   | [Darstellung & Grundeinstellungen](/verwalten/darstellung/#allgemeines)                        |
| **Mein Lotta** → **Darstellung**                | Farben, Schriften, Hintergrundbild, Vorlagen             | [Darstellung & Grundeinstellungen](/verwalten/darstellung/#darstellung)                        |
| **Mein Lotta** → **Kalender**                   | Kalender und Termine der Schule                          | [Kalender](/verwalten/kalender/)                                                               |
| **Mein Lotta** → **Nutzung**                    | Speicherplatz, Medien und aktive Nutzer pro Monat        | [Nutzung, Speicher & Statistiken](/verwalten/nutzung-und-statistiken/)                         |
| **Mein Lotta** → **Statistiken**                | Besuche und Seitenaufrufe Ihrer Website                  | [Nutzung, Speicher & Statistiken](/verwalten/nutzung-und-statistiken/#statistiken)             |
| **Mein Lotta** → **Feedback**                   | Rückmeldungen der Mitglieder beantworten                 | [Feedback bearbeiten](/verwalten/feedback/)                                                    |
| **Nutzer und Gruppen** → **Nutzer**             | Mitglieder suchen, Gruppen zuweisen, löschen             | [Mitglieder verwalten](/verwalten/mitglieder/)                                                 |
| **Nutzer und Gruppen** → **Gruppen**            | Gruppen, Admin-Rechte, Einschreibeschlüssel              | [Gruppen](/verwalten/gruppen/)                                                                 |
| **Nutzer und Gruppen** → **Einschränkungen**    | Speicherplatz begrenzen, Anmeldung per E-Mail            | [Nutzung, Speicher & Statistiken](/verwalten/nutzung-und-statistiken/#speicherplatz-begrenzen) |
| **Kategorien und Marginalien** → **Kategorien** | Das Menü Ihrer Website                                   | [Kategorien](/verwalten/kategorien/)                                                           |
| **Kategorien und Marginalien** → **Marginale**  | Kalender, Vertretungsplan, Webseiten neben den Beiträgen | [Marginalen](/verwalten/marginalen/)                                                           |
| **Hilfe** → **Dokumentation**                   | Diese Dokumentation                                      |                                                                                                |

Mit **Bereich verlassen** kehren Sie zur Website zurück.

Neue Beiträge, die auf Ihre Freigabe warten, finden Sie nicht hier, sondern unter
**Mein Profil** → **Beiträge veröffentlichen** (siehe [Beiträge freigeben & anpinnen](/verwalten/beitraege-freigeben/)).

<Aside type="note">

Wer Admin ist, legen Sie über Gruppen fest: Alle Mitglieder einer Gruppe mit Administratorrechten sind Admins (siehe [Gruppen](/verwalten/gruppen/#berechtigungen)).

</Aside>

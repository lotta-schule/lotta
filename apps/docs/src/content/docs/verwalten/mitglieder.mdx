Unter **Seite verwalten** → **Nutzer** finden Sie alle Mitglieder Ihrer Lotta-Seite.

<Screenshot
  name="admin-users"
  alt="Die Nutzerverwaltung mit Suche, Filtern und der Liste der Mitglieder"
/>

## Mitglieder finden

- **Nach Namen suchen:** Geben Sie einen Teil des Namens ein.
- **Nach Gruppe filtern:** Zeigt nur die Mitglieder einer Gruppe, oder alle, die noch zu keiner
  Gruppe gehören. So finden Sie z.B. neue Lehrkräfte, die Sie noch zuordnen müssen.
- **Zuletzt angemeldet:** Zeigt Mitglieder, die sich z.B. seit 90 Tagen, sechs Monaten oder
  einem Jahr nicht mehr angemeldet haben. Praktisch, um verwaiste Konten aufzuräumen.

## Ein Mitglied einer Gruppe zuweisen

<Steps>

1. Klicken Sie auf das Mitglied. Es öffnet sich das Fenster **„Name“ bearbeiten**.
2. Wählen Sie unter **Gruppe zuweisen** eine oder mehrere Gruppen aus.
3. Klicken Sie auf **speichern**.

</Steps>

<Screenshot
  name="admin-users-edit"
  alt="Das Fenster zum Bearbeiten eines Mitglieds mit zugewiesenen Gruppen"
/>

Darunter sehen Sie die Gruppen, in die sich das Mitglied selbst über Einschreibeschlüssel
eingetragen hat. Diese können Sie hier nicht entfernen; sie enden, wenn Sie den Schlüssel der
Gruppe ändern.

Direkt zugewiesene Gruppen bleiben auch dann bestehen, wenn Sie den Einschreibeschlüssel der
Gruppe ändern (siehe [Einschreibeschlüssel](/verwalten/einschreibeschluessel/#zwei-wege-in-eine-gruppe)).

<Aside type="tip" title="Admins festlegen">

Ein Mitglied wird Admin, indem Sie es einer Gruppe mit Administratorrechten zuweisen (siehe [Gruppen](/verwalten/gruppen/#berechtigungen)). Entfernen Sie es aus der Gruppe, verliert es die Admin-Rechte.

</Aside>

## Ein Benutzerkonto löschen

Klicken Sie im Fenster des Mitglieds auf **Benutzer löschen** und bestätigen Sie mit
**endgültig löschen**.
Mitglieder können ihr Konto auch selbst löschen (siehe [Mein Profil](/nutzen/profil/#benutzerkonto-löschen)).

<Aside type="note">

Passwörter von Mitgliedern können Admins weder sehen noch ändern. Wer sein Passwort vergessen hat, setzt es selbst zurück (siehe [Passwort vergessen](/erste-schritte/anmelden/#passwort-vergessen)).

</Aside>

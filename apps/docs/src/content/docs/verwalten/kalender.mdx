Lotta hat eigene Kalender für die Termine Ihrer Schule. Sie zeigen sie in
[Kalender-Marginalen](/verwalten/marginalen/#kalender-marginale) an und können sie per Link zum
Abonnieren freigeben.

Öffnen Sie **Seite verwalten** → **Kalender**. Sie sehen alle Termine in der Monatsansicht.

<Screenshot
  name="admin-calendar"
  alt="Die Kalenderansicht im Administrationsbereich mit Terminen"
/>

## Einen Kalender anlegen

<Steps>

1. Klicken Sie auf **Kalender verwalten** und dann auf **Kalender erstellen**.
2. Geben Sie einen Namen ein, z.B. „Schultermine“ oder „Klausurtermine“, und wählen Sie eine Farbe.
3. Klicken Sie auf **Kalender erstellen**.

</Steps>

Legen Sie so viele Kalender an, wie Sie brauchen, z.B. einen öffentlichen für die Schule und einen
internen für das Kollegium. Wer welche Termine sieht, bestimmen Sie über die
[Marginalen](/verwalten/marginalen/), in denen Sie die Kalender anzeigen.

## Einen Termin eintragen

<Steps>

1. Klicken Sie auf **Ereignis erstellen**.
2. Geben Sie **Name** und bei Bedarf eine **Beschreibung** ein, z.B. den Ort.
3. Wählen Sie den **Kalender**, in dem der Termin stehen soll.
4. Legen Sie die Zeit fest:
   - **ganztägig** für Termine ohne Uhrzeit, z.B. Wandertage
   - ohne Haken bei **ganztägig** mit **Startzeit** und **Endzeit**
   - **mehrtägig** mit **Enddatum**, z.B. für Klassenfahrten.
5. Wählen Sie bei Bedarf eine **Wiederholung**: täglich, wöchentlich, zweiwöchentlich, monatlich oder jährlich.
6. Klicken Sie auf **speichern**.

</Steps>

<Screenshot
  name="admin-calendar-event"
  alt="Das Fenster „Ereignis erstellen“"
/>

Um einen Termin zu ändern oder zu löschen, klicken Sie im Kalender darauf. Beim Löschen eines
wiederkehrenden Termins werden alle seine Wiederholungen gelöscht.

## Einen Kalender teilen

Mit einem öffentlichen Link können Eltern, Lehrkräfte sowie Schülerinnen und Schüler den Kalender in
ihrer eigenen Kalender-App abonnieren und sehen neue Termine automatisch.

<Steps>

1. Klicken Sie auf **Kalender verwalten** und beim gewünschten Kalender auf **bearbeiten**.
2. Setzen Sie den Haken bei **Dieser Kalender sollte über einen Link öffentlich zugänglich sein** und klicken Sie auf **speichern**.
3. Öffnen Sie den Kalender erneut und kopieren Sie den **Öffentlichen Link** mit **Link in die Zwischenablage kopieren**.
4. Geben Sie den Link weiter, z.B. in einem öffentlichen Beitrag.

</Steps>

<Aside type="caution">

Jede Person, die den Link kennt, kann alle Termine dieses Kalenders sehen. Teilen Sie interne Kalender nicht über einen öffentlichen Link.

</Aside>

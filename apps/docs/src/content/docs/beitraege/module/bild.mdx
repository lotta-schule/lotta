Das Bildmodul zeigt ein einzelnes Bild über die ganze Breite des Beitrags.

<Steps>

1. Klicken Sie auf **Bild**.
2. Fahren Sie mit der Maus über das Bild und klicken Sie auf **Bild wechseln**. Wählen Sie ein Bild aus Ihren Dateien oder laden Sie eines hoch.
3. Tragen Sie unter dem Bild eine **Bildbeschreibung** ein, z.B. was zu sehen ist oder woher das Bild stammt.

</Steps>

## Darstellung

Normalerweise passt Lotta das Bild so an, dass es vollständig auf den Bildschirm passt. Bei sehr
hohen Bildern, z.B. einem Plakat, setzen Sie in den **Moduleinstellungen** den Haken bei
**Bild in voller Höhe anzeigen**. Dann müssen Lesende eventuell scrollen.

<Aside type="tip">

Für mehrere Bilder nehmen Sie die [Galerie](/beitraege/module/galerie/). Achten Sie bei Fotos von Personen auf die Einwilligung der Abgebildeten.

</Aside>

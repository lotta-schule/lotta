---
title: Trennlinie
description: Das Modul Trennlinie trennt Abschnitte eines Beitrags optisch voneinander.
sidebar:
  order: 60
---

Eine Trennlinie setzt einen sichtbaren Schnitt zwischen zwei Abschnitten eines Beitrags, z.B.
zwischen einem Bericht und den Terminen dazu. Klicken Sie auf **Trennlinie**; das Modul hat keine
weiteren Einstellungen. Verschieben Sie die Linie mit den Pfeilen an die richtige Stelle.

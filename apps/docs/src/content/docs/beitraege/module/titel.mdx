Mit dem Titelmodul gliedern Sie längere Beiträge durch Zwischenüberschriften.

<Steps>

1. Klicken Sie auf **Titel**.
2. Ersetzen Sie „Deine Überschrift ...“ durch Ihre Überschrift.
3. Über das Zahnrad (**Moduleinstellungen**) wählen Sie die Größe: **Überschrift groß**, **Überschrift mittel** oder **Überschrift klein**.

</Steps>

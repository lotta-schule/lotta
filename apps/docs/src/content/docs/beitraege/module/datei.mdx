Mit dem Modul **Dateien** bieten Sie Dateien zum Herunterladen an, z.B. Arbeitsblätter,
Elternbriefe oder Präsentationen.

<Steps>

1. Klicken Sie auf **Dateien**.
2. Klicken Sie auf **Datei hinzufügen** und wählen Sie eine oder mehrere Dateien aus.
3. Geben Sie jeder Datei eine **Beschreibung des Downloads**, damit Lesende wissen, was sie herunterladen.

</Steps>

<Screenshot
  name="module-download"
  alt="Ein Dateimodul mit zwei Dateien zum Herunterladen"
/>

In den **Moduleinstellungen** legen Sie fest, ob zu den Dateien **Vorschaubilder** angezeigt
werden.

Sie können jede Art von Datei anbieten. Wählen Sie aber Formate, die alle öffnen können: PDF
statt Word-Dokumenten, wenn nichts bearbeitet werden muss. PDFs und Bilder öffnen sich beim
Anklicken direkt im Browser.

Ein Beitrag besteht aus Modulen. Jedes Modul ist ein Baustein für eine Art von Inhalt. Sie
fügen Module unter der Beitragsvorschau mit einem Klick hinzu.

<Screenshot
  name="article-editor-modules"
  alt="Die Leiste zum Hinzufügen von Modulen im Bearbeitungsmodus"
/>

| Modul                                       | Wofür?                                                              |
| ------------------------------------------- | ------------------------------------------------------------------- |
| [Text](/beitraege/module/text/)             | Fließtext mit Formatierungen, Links, Listen und Bildern             |
| [Titel](/beitraege/module/titel/)           | Zwischenüberschriften in drei Größen                                |
| [Bild](/beitraege/module/bild/)             | Ein einzelnes, großes Bild mit Bildunterschrift                     |
| [Galerie](/beitraege/module/galerie/)       | Mehrere Bilder als Raster oder zum Durchblättern                    |
| [Dateien](/beitraege/module/datei/)         | Arbeitsblätter, Präsentationen und andere Dateien zum Herunterladen |
| [Trennlinie](/beitraege/module/trennlinie/) | Eine Linie, die Abschnitte voneinander trennt                       |
| [Tabelle](/beitraege/module/tabelle/)       | Einfache Tabellen, z.B. Termine oder Ergebnisse                     |
| [Formular](/beitraege/module/formular/)     | Kontaktformulare, Anmeldungen, Umfragen                             |
| [Video](/beitraege/module/video/)           | Videos, die direkt im Beitrag abgespielt werden                     |
| [Audio](/beitraege/module/audio/)           | Tonaufnahmen, Podcasts, Musik                                       |

## Module bearbeiten

Fahren Sie mit der Maus über ein Modul (auf dem Smartphone: tippen Sie darauf). Rechts oben
erscheinen die Werkzeuge des Moduls:

<Screenshot
  name="article-module-toolbar"
  alt="Ein Modul mit seinen Werkzeugen: ① Pfeile zum Verschieben, ② Moduleinstellungen, ③ Modul löschen"
/>

- ① **Pfeile:** verschieben das Modul um eine Stelle nach oben oder unten.
- ② **Zahnrad** (**Moduleinstellungen**): öffnet die Einstellungen des Moduls, z.B. die Größe einer
  Überschrift oder den Stil einer Galerie. Nicht jedes Modul hat Einstellungen.
- ③ **Papierkorb** (**Modul löschen**): entfernt das Modul aus dem Beitrag.

<Aside type="note">

Änderungen an Modulen werden erst mit **speichern** unten im Beitrag übernommen.

</Aside>

## Dateien auswählen

Bild, Galerie, Dateien, Video und Audio öffnen zum Auswählen den Dateibrowser. Dort können Sie:

- eine Datei aus Ihren Ordnern auswählen oder suchen,
- eine neue Datei hochladen (auch per Drag & Drop),
- eine Datei aus den öffentlichen Ordnern Ihrer Schule übernehmen.

Mehr dazu unter [Meine Dateien](/nutzen/dateien/).

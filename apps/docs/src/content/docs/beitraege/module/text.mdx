Das Textmodul ist das wichtigste Modul: Hier schreiben Sie den Fließtext Ihres Beitrags.

<Steps>

1. Klicken Sie unter der Beitragsvorschau auf **Text**.
2. Ersetzen Sie „Dein Text ...“ durch Ihren Text.
3. Markieren Sie Text und formatieren Sie ihn mit den Symbolen der Werkzeugleiste.

</Steps>

<Screenshot name="module-text" alt="Ein Textmodul mit seiner Werkzeugleiste" />

## Formatierungen

| Symbol         | Wirkung                                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| B · I · U      | fett, kursiv, unterstrichen                                                                                            |
| Kette          | Link einfügen: Text markieren, auf das Symbol klicken, die vollständige Adresse eingeben (z.B. `https://lotta.schule`) |
| Liste          | Aufzählung oder nummerierte Liste                                                                                      |
| Bild           | ein Bild an der Stelle des Cursors einfügen                                                                            |
| kleine Schrift | für Hinweise, Quellen oder Zitate in kleinerer Schrift                                                                 |

## Bilder im Text

Setzen Sie den Cursor an die gewünschte Stelle und klicken Sie auf das Bild-Symbol. Wählen Sie
ein Bild aus [Meine Dateien](/nutzen/dateien/) oder laden Sie eines hoch. Über dem eingefügten
Bild legen Sie fest, ob es links oder rechts steht und wie groß es ist (**XL**, **M** oder **S**).

<Aside type="tip">

Wenn Sie Text aus Word oder einer Website kopieren, entfernt Lotta die fremden Formatierungen. So sehen alle Beiträge einheitlich aus. Formatieren Sie den Text danach in Lotta.

</Aside>

Für Zwischenüberschriften nutzen Sie das Modul [Titel](/beitraege/module/titel/), für einzelne
große Bilder das Modul [Bild](/beitraege/module/bild/).

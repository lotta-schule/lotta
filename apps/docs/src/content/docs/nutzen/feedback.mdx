Etwas funktioniert nicht, oder Sie haben eine Idee? Schicken Sie den Admins Ihrer Schule eine
Rückmeldung.

<Steps>

1. Öffnen Sie **Mein Profil** → **Feedback**.
2. Wählen Sie ein Thema oder beschreiben Sie es kurz, und schreiben Sie Ihre Nachricht. Je genauer, desto besser: Was haben Sie getan, was ist passiert, was hätten Sie erwartet?
3. Lotta fügt Informationen über Ihr Gerät und Ihren Browser hinzu, damit sich ein Fehler leichter finden lässt. Löschen Sie Zeilen, die Sie nicht teilen möchten.
4. Klicken Sie auf **an Administratoren senden**.

</Steps>

<Screenshot
  name="feedback-dialog"
  alt="Das Fenster „Feedback schreiben“ mit Thema, Nachricht und Systeminformationen"
/>

Die Admins antworten Ihnen per E-Mail. Fragen, die Lotta selbst betreffen, leiten sie an das
Lotta-Team weiter.

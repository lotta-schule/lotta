Neben den Beiträgen zeigt Lotta Marginalen: kleine Fenster mit Terminen, dem Vertretungsplan
oder anderen Informationen. Welche Marginalen erscheinen, hängt von der Kategorie und von Ihren
Gruppen ab. Auf dem Smartphone finden Sie sie im Menü.

<Screenshot
  name="widgets-calendar"
  alt="Eine Kalender-Marginale neben den Beiträgen einer Kategorie"
/>

## Termine

Eine Kalender-Marginale listet die nächsten Termine aus einem oder mehreren Kalendern der
Schule. Öffentliche Kalender sehen alle, interne Kalender (z.B. für das Kollegium) nur die
jeweiligen Gruppen.

<Aside type="tip">

Möchten Sie die Termine der Schule in Ihrem eigenen Kalender auf dem Smartphone oder am Computer sehen? Fragen Sie nach dem öffentlichen Link des Kalenders. Damit können Sie ihn in jeder Kalender-App abonnieren und bleiben automatisch auf dem Laufenden.

</Aside>

## Persönlicher Vertretungsplan

Nutzt Ihre Schule die Stundenplan-Software von Indiware, kann Lotta Ihren persönlichen Stunden-
und Vertretungsplan anzeigen. Dafür muss Lotta wissen, wer Sie sind:

<Steps>

1. Öffnen Sie **Mein Profil** → **Meine Daten**.
2. Tragen Sie unter **Meine Klasse / Mein Kürzel** Ihre Klasse (z.B. `8a`) oder als Lehrkraft Ihr Kürzel (z.B. `Mei`) ein, genau so, wie es im Vertretungsplan steht.
3. Klicken Sie auf **Speichern**.

</Steps>

Bleibt der Vertretungsplan leer, stimmt meist die Schreibweise nicht. Fragen Sie im Zweifel bei
der Schulleitung nach.

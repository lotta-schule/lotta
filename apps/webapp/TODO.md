  drüber steht), der sollte im Gegensatz zum Feldnamen auch leer sein können
  drüber

  'E-Mail-Adresse', 'E-Mail-Adresse (2)', usw.
- Icon für Datumsfeld hinzufügen
- Im Bearbeitungsmodus sollte Dateiauswahl-Feld disabled sein
- Im Bearbeitungsmodus sollte 'Formulareinsendungen sehen' disabled sein, wenn's keine Einsendungen gibt
- Wenn das Formular ein Dateifeld hat, **MUSS** eine E-Mail-Adresse (Formulardaten versenden) eingegeben werden, der
  Text dass Dateianhänge nicht gespeichert werden soll dann auch unter dieses Feld kommen
